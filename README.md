# Classic Fond CD

Каталог игр со сборника на CD «Лучшие игры для IBM PC» (1995) в стиле Norton Commander: поиск, фильтры, обложки и скриншоты, longplay с YouTube, ссылки «играть в браузере» на dos.zone, упоминания в прессе.

Открыть: https://einner.github.io/classicfond-cd/

Описания, обложки и скриншоты — [old-games.ru](https://www.old-games.ru); пресса — [retroindex](https://retroindex.github.io); игры в браузере — [dos.zone](https://dos.zone).
